# Orbit Cinema - Movie Search

A single-page, black-and-purple space-themed movie search app built with React + Vite.

## What It Does

- Single main page only (no additional detail routes)
- Search local movie catalog by title, genre, director, or year
- Shows featured movies when no search query is entered
- No external API setup or API keys required

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
